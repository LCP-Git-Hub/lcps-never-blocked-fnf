# FNF LCPS NEVER BLOCKED

Personal offline Chromebook copy of Friday Night Funkin' v0.8.6. Your way.

## Download and play

Open this repository's **Releases** page and download **FNF-LCPS-All-in-One.html/source code**. The file is approximately 974 MB. On a Chromebook, save it in Downloads, open it with Chrome, wait for loading, and click **Play offline**. All game data is embedded in the file.

The game HTML is a release attachment, not a normal Git file. GitHub blocks ordinary Git files larger than 100 MiB; release attachments can be under 2 GiB.
